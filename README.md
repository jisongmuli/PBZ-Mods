# 影之刃零：堡主操控、魂·巅峰与影境再战

三个独立 Windows / Steam Mod，分别使用 F7、F8、F9。堡主操控为供实操反馈的首版。

## 下载与安装

到 [v2.1.0 发布页](https://github.com/jisongmuli/PBZ-Mods/releases/tag/v2.1.0) 下载：

| 文件 | 内容 |
| --- | --- |
| PBZ-BossControl-v0.1.0-alpha.zip | F7 堡主操控独立测试版 |
| PBZ-HunPeak-v1.1.2.zip | F8 魂·巅峰，增加堡主切换兼容 |
| PBZ-RiftArena-v2.1.0.zip | F9 影境再战，增加堡主切换兼容 |
| PBZ-Mods-v2.1.0.zip | 三个独立 Mod 的合包，推荐同时使用时下载 |

1. 正常退出游戏，再将 ZIP 解压到游戏安装根目录，让包内 ProjectPBZ 合并到现有目录。
2. 三个同名前缀的 .pak、.utoc、.ucas 必须一起位于 ProjectPBZ/Content/Paks/~mods。
3. 保留包中的 Saved/CodexBossControl、CodexHunPeak、CodexRiftArena 空目录，供设置、诊断和恢复记录使用。
4. 重启游戏。路径自动按实际安装位置解析，支持其他盘符和带空格的路径。

与堡主操控合用时请同时升级另外两包。旧版本只识别主角，尚无 F7 切换兼容。不要启用旧合并测试包 zzz_CodexFinalForm_P 或开发探针 zzzz_CodexRiftLab_P。

## 堡主操控 0.1.0

- F7 开启／关闭魔渊状态，恢复主角后进行交互与探索。
- 左键每按一次接一段，共五段原生连招，最多缓存一次；保留原生技能时序和 Boss 抗打断配置。
- WASD／鼠标移动与镜头，右键重击，空格加方向闪避，中键锁定，Tab 换目标。
- Q、E、R、左 Ctrl 四个技能槽；F6 配置，1–4 选槽位，方向键选择招式，Enter 装备。
- 27 个候选主动招式。生命比例与技能冷却跨 F7 切换延续，角色替换时暂缓正常存档写入。
- 暂未开放抓取／处决、依赖龙柱的完整转阶段及技能轮盘；原生数值尚未统一平衡到主角成长。

[堡主操控说明](docs/CodexBossControl.md)

## 魂·巅峰与影境再战

- F8 开关原生最终黑伤剑状态；进入堡主前暂停增强，退出后恢复先前偏好。
- 首次三魔偶剧情结束后，可从圣母像裂缝重复进入。入口旁放置铃铛，在前方庭院挑战。
- 87 个可选形态，最多五个相同或不同 Boss。生命、杀气、伤害分别设置 1–20 整数倍率。
- 伤害以原版的一半为基准：×1 为 50%，×2 为 100%，×20 为 1000%。
- 原版配乐开关；当前场地用第一个 Boss 的配乐，原剧情场地交给原生阶段流程。
- 当前场地挑战、原剧情场地仅战斗、原剧情完整流程；原剧情模式限单 Boss，保留原生转阶段。
- F7 切换保留同一场挑战，并重新绑定战斗服务；F9 先恢复主角，再清场返回。
- 击杀后留在现场，由玩家手动 F9 返回。原剧情模式通过独立快照恢复装备、物品和主线进度。

[魂·巅峰说明](docs/CodexHunPeak.md) · [影境再战说明](docs/CodexRiftArena.md)

## 验证与限制

自动检查覆盖逐段输入、缓存、原生衔接窗口、冷却延续、角色身份切换与 F9 恢复，以及既有再战功能。

隔离副本使用原生游戏接口进行代表性测试；这不能替代所有地图、敌人、剧情分支和实际键鼠输入的完整验证。首版交由玩家进一步实操反馈。完整测试统计见 VALIDATION.json。

本仓库不附带个人存档、账号信息、运行日志、研究转储或解包工具。src 为自编 Mod 代码和资源路径映射，hooks 为追加挂钩片段；原生启动／菜单模块只位于运行补丁包中。

源码检查：安装 Node.js 后运行 `node --test tests/*.test.js`。构建仍需要匹配的游戏原生模块及 Pak / IoStore 工具，仓库未附带游戏原文件与工具二进制。
