# 堡主操控 0.1.0：独立测试版

F7 开启／关闭暗魔天堡之主“魔渊”的操控状态。关闭后在当前位置恢复原主角、装备和镜头，再进行铃铛交互、探索等操作。

## 操作

- WASD 移动，鼠标控制第三人称镜头。
- 左键每按一次推进一段原生连招，共五段；最多缓存一次后续输入，不自动播放整套。原生衔接窗口之外会等待，不强行打断出招。
- 右键重击；部分轻攻击进度可接重击分支。
- 空格＋方向使用堡主原生方向闪避。
- 鼠标中键锁定／解除锁定，Tab 切换目标。
- Q、E、R、左 Ctrl 使用四个技能槽。技能有额外冷却，关闭再开启 F7 不刷新冷却。
- F6 打开／关闭技能配置面板；1–4 选择槽位，左右方向键选择招式，Enter 装备。共 27 个候选主动招式，使用原生资源编号显示，便于反馈。面板会暂停游戏，关闭后恢复。
- F9 仍由影境再战负责：先恢复主角，再清场返回铃铛。击败对手后不会自动传送。

保留原生 Boss 的抗打断配置和技能时序。未额外加入永久无敌或无限伤害。原生抓取／处决、依赖场景龙柱的完整转阶段与技能轮盘尚未开放；首版先验证基本操控、逐段连招和主动技能配置。

## 切换与状态

血量按比例在主角与堡主之间延续；不会通过 F7 自动补满。首版使用堡主原生生命与攻击数值，尚未做主角成长数值的统一平衡，需根据实操反馈调整。

接管期间冻结并隐藏原主角；恢复时撤销本 Mod 的角色、镜头和所属召唤物。剧情演出或读盘时退出堡主状态。角色替换期间使用独立来源的临时保存禁令，防止把 NPC 控制状态写进正常存档；恢复主角后释放。

与魂·巅峰互斥：开启堡主前暂时撤销魂·巅峰，F7 关闭后恢复原先偏好；按 F8 会先回到主角再处理魂·巅峰开关。

设置保存在 `ProjectPBZ/Saved/CodexBossControl/settings.json`，可编辑键位；槽位也可以直接在 F6 面板修改。状态与错误记录位于同目录 `status.json`。

## 安装

正常退出游戏后，将以下三个文件一起放入 `ProjectPBZ/Content/Paks/~mods`：

- `zzz_CodexBossControl_P.pak`
- `zzz_CodexBossControl_P.utoc`
- `zzz_CodexBossControl_P.ucas`

与其他两个 Mod 同时使用时，请一并更新到魂·巅峰 1.1.2、影境再战 2.1.0 或更新版本，旧版尚无角色切换兼容处理。三个 Mod 使用不同启动文件，可分别安装、卸载；堡主操控不包含开发探针。

卸载前先 F7 恢复主角，若在挑战中再 F9 返回铃铛，然后正常退出游戏并移出三个文件。

这是供实操反馈的首版。全部地图、剧情分支、特殊敌人及键鼠组合尚未逐一验证。请反馈对应技能编号、所处模式、按键顺序和异常现象。
